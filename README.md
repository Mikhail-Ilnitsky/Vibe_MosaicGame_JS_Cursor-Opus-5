# Игра-мозаика

Адаптивная браузерная мозаика: картинка делится на квадратные фрагменты, которые нужно собрать обратно. Это чистый фронтенд-SPA без сборщика, базы данных и бэкенда.

**Демо:** [mikhail-ilnitsky.github.io/Vibe_MosaicGame_JS_Cursor-Opus-5](https://mikhail-ilnitsky.github.io/Vibe_MosaicGame_JS_Cursor-Opus-5/)

## Возможности

- Галерея картинок с локализацией названий (RU / EN, переключатель в правом верхнем углу)
- Автоматический расчёт квадратных сеток сложности: N = 5…11 частей по меньшей стороне, число частей по большей стороне считается так, чтобы фрагменты остались строго квадратными, а остаток исходника обрезается по центру
- Фрагменты — это `<div>` с общим `background-image`; сдвиг задаётся только процентами, поэтому картинка не режется физически и не «плывёт» при любом размере поля
- Два способа управления сразу: клик-клик и перетаскивание на Pointer Events (мышь и палец), порог перехода в drag — половина плитки
- Игровое поле вписывается в свободную область экрана без прокрутки и не растягивается больше масштаба 1:1
- Счётчик ходов во время игры и в финальном сообщении
- Просмотр оригинала — та же обрезанная область в том же размере, что и пазл
- Анимация победы: жёлтая вспышка сетки на 500 мс, затем сетка исчезает и остаётся собранная картинка с сообщением и кнопкой новой игры

## Стек

| Технология | Назначение | Версия |
|---|---|---|
| HTML | разметка SPA, точка входа `docs/index.html` | HTML5 |
| CSS | вёрстка, адаптив, фрагменты через `background-image`, CSS Grid, custom properties | CSS3 |
| JavaScript | галерея, расчёт сетки, i18n, управление, победа | ES2015+ (ES6, ванильный) |

Сборщик, компиляция и внешние зависимости не используются. Локальные пути к скриптам и стилям — относительные (`./...`).

## Запуск локально

Достаточно открыть `docs/index.html` в браузере. Либо поднять любой статический сервер:

```bash
python3 -m http.server -d docs 8080
# затем http://localhost:8080
```

## Деплой на GitHub Pages

В **Settings → Pages** источник — ветка по умолчанию (`main`), папка **`/docs`**. Дополнительная сборка не нужна: файлы сайта уже лежат в `docs/`.

## Происхождение проекта

Исходная версия сгенерирована в Cursor по техническому заданию [`prompts/INITIAL.md`](prompts/INITIAL.md). Подробный контекст для следующих сессий — в [`.cursor/CONTEXT.md`](.cursor/CONTEXT.md).

## Структура

```
.
├── docs/
│   ├── index.html          # точка входа SPA: шапка, три экрана, подключение скриптов
│   ├── css/
│   │   └── styles.css      # минималистичные стили, адаптив, анимации, сетка поля
│   └── js/
│       ├── images.js       # фиксированный массив картинок + загрузка их размеров
│       ├── i18n.js         # строки RU/EN, определение и переключение языка
│       ├── grid.js         # расчёт сеток 5…11 и процентных фонов фрагментов
│       ├── game.js         # поле: рендер, клик-клик, drag, ходы, оригинал, победа
│       └── app.js          # экраны (галерея → сложность → игра) и их связывание
├── prompts/
│   └── INITIAL.md          # исходное техническое задание
├── .cursor/
│   └── CONTEXT.md          # краткий контекст проекта
└── README.md
```
